# Profil Kampus Universitas Pancasila

Website sederhana yang dibuat menggunakan HTML untuk menampilkan informasi mengenai Universitas Pancasila.

## Isi Website

- Identitas Kampus
- Foto Gedung
- Program Keahlian
- Alur Pendaftaran
- Kontak dan Media Sosial

## Teknologi

- HTML5

## Hasil

Website menggunakan navigasi internal untuk berpindah ke setiap bagian informasi kampus serta menyediakan tautan media sosial dan kontak Universitas Pancasila.
